# Data Cleaning & Visualization Project

This project follows the linked tutorial's practical data cleaning workflow: inspect the data, resolve missing and invalid values, remove duplicate records, review outliers, and communicate patterns with charts.

## Dataset

There was no raw dataset in the project workspace, so `retail_orders_raw.csv` is a reproducible **synthetic** retail-orders dataset generated by `cleaning_project.py`. It intentionally contains missing values, duplicate order IDs, invalid quantities/prices, and high price outliers. It contains no real customer or business information.

## Run it

Install Python 3.9+ and the dependencies, then run:

```bash
python -m pip install pandas numpy
python cleaning_project.py
```

The script regenerates the raw and cleaned CSVs, three chart images, and `report.html`.

## Cleaning choices

- Keep the first row for each `order_id` and remove subsequent duplicates.
- Remove rows where quantity or unit price is zero or negative.
- Fill missing region with `Unknown` and ratings with the observed median.
- Identify unit-price outliers with 1.5×IQR fences and cap prices at those limits.
- Recalculate revenue from cleaned quantity and price.

These are teaching choices, not universal rules. For a real dataset, validate them with its owner and business context before using the cleaned values.

## Outputs

- `report.html`: concise findings and charts
- `retail_orders_raw.csv`: generated input with intentional quality issues
- `retail_orders_clean.csv`: cleaned output
- `charts/`: monthly revenue, revenue by category, and price distribution (portable SVG)
- `cleaning_project.py`: full reproducible workflow
